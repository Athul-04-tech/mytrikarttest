# Production & Staging Frontend Deployment Guide

This document describes how to deploy the static build artifacts (`dist/`) generated by Vite for **MytriKart Frontend**.

---

## 1. Nginx Deployment Configuration (Staging / VPS)

When serving the `dist/` directory behind Nginx, configure SPA client-side routing fallback and HTTP caching headers.

```nginx
server {
    listen 80;
    server_name staging.mytrikart.com;

    root /var/www/mytrikart/dist;
    index index.html;

    # 1. Single Page Application (SPA) Fallback
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 2. Immutable Caching for Hashed Assets (JS, CSS, Media)
    location /assets/ {
        expires 1y;
        add_header Cache-Control "public, max-age=31536000, immutable";
    }

    # 3. No-Cache for HTML Entry Point
    location = /index.html {
        expires -1;
        add_header Cache-Control "no-store, no-cache, must-revalidate, proxy-revalidate, max-age=0";
    }
}
```

## 2. AWS S3 + CloudFront Deployment Configuration (Production)

### AWS S3 Static Website Hosting / Origin Setup
- Upload `dist/` contents to your target S3 Bucket.
- **Index Document**: `index.html`
- **Error Document**: `index.html`

### CloudFront Custom Error Responses (SPA Routing)
To handle deep links (e.g. `/admin/products`, `/seller/dashboard`, `/checkout`):
- **HTTP Error Code**: `404: Not Found`
- **Customize Error Response**: `Yes`
- **Response Page Path**: `/index.html`
- **HTTP Response Code**: `200: OK`
- **Error Caching Minimum TTL**: `0` seconds

### CloudFront Cache Policy
- `/assets/*` → Cache for 1 year (`Cache-Control: public, max-age=31536000, immutable`).
- `/index.html` → Minimum TTL 0 (`Cache-Control: no-cache`).

## 3. Environment Variable Injection at Build Time

The frontend API origin is configured at build time via `VITE_API_BASE_URL`.

```bash
# Example Staging Build
export VITE_API_BASE_URL="https://api-staging.mytrikart.com"
npm run build

# Example Production Build
export VITE_API_BASE_URL="https://api.mytrikart.com"
npm run build
```

Production builds will fail loudly if `VITE_API_BASE_URL` is missing, empty, or points to `localhost`/`127.0.0.1`.
